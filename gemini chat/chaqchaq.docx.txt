Telegram serveri bir token bilan ikki joyda ishlashga ruxsat bermaydi va biri ikkinchisini uzib yuboradi.
Muammoni qanday hal qilasiz?
Kompyuteringizni tekshiring: Agar kompyuteringizda terminalda (PyCharm, VS Code yoki CMD da) python bot.py yoki shunga o'xshash buyruq ishlab turgan bo'lsa, uni darhol to'xtating (Ctrl + C bosing). Bot faqat bitta joyda — faqat Render.com serverida ishlashi kerak.
Render'da dublikat (ortiqcha servis) bor-yo'qligini tekshiring: Render.com paneliga kirib, adashib bitta loyiha uchun ikkita Web Service yoki Background Worker ochib yubormaganingizni tekshiring. Agar ikkita bo'lsa, bittasini o'chirib tashlang yoki to'xtating (Suspend).
Shu ikkita narsani to'g'rilasangiz, konflikt yo'qoladi va botingiz guruhda ham, lichkada ham barqaror ishlay boshlaydi!
